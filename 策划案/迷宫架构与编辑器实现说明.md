# 迷宫架构与编辑器实现说明

当前项目：`E:\xx\Maze`。当前发布目录只有一关手工搭建的竞品参考关，不再使用随机生成器。

## 场景与 UI

`MazeSceneRoot.prefab` 承载 Map/Left、Middle、Right、FoldRegion、小球和目标。地图为 MeshRenderer 场景资源，小球和目标各有独立预制体。沿用项目当前的 `Camera.main`，没有新增相机。

`UICorePlay` 由现有 UI 框架管理，`MazeHudView` 仅处理标题、提示、折叠、重开、选关与弹窗。`MazePresenter` 负责组合会话、场景和 UI，玩法规则不依赖 UI。

## 数据与玩法

- `MazeLevelData`：手工关卡配置，含名称、设计说明、地图内容版本、道路数组和折叠区域。
- `MazeMap`：运行时复制配置，不向视图开放可写数组。
- `FoldMazeRules`：四向邻接、折叠接缝、状态图寻路、最少切换次数。
- `FoldMazeGameplay`：连续移动、同次手势转弯、松手吸附、经过出口即完成、提示消费。
- `MazeSession`：关卡选择、存档、广告奖励去重与完成记录。
- `MazeLevelValidator`：校验手工地图可解性、道路可逆性。不负责生成关卡。

后续推箱子和双球玩法应各自实现独立状态与规则类，使用 `IMazeGameplay` 生命周期接口，不在折叠规则中加入混杂分支；接入时还需扩展应用层玩法选择与对应呈现。

## 网格与性能

路宽为 1 格，倒角半径为 0.16 格。外侧圆角和内侧小倒角只依据展开地图确定，各顶点限制在所属分区内。三块道路网格在装载新地图时创建，同关重开复用；折叠期间只改 Transform 和可见性，不重建、不替换网格，不调整接缝圆角。

当前 15×21 地图道路共 2,812 个顶点，三个 MeshRenderer；折叠后隐藏中间 Renderer。此为几何统计，不代表真机帧率或完整场景 Draw Call 数。没有每格一个 GameObject，也没有每帧创建道路纹理。提示改变时才刷新提示对象。

折叠动画中的中间区域缩放围绕自身中心，结束后隐藏；左右只做平移。折叠区域背景色轻微区别于主体，不盖住道路。

## 移动与缓存

任意非 UI 区域可起手，手指不必点中小球或地图。一根手指按住可连续改变方向；转弯时衔接最近的合法格中心，墙壁阻挡无效转向。松手吸附，经过出口格边界立即完成，不必停留。

松手吸附完成、折叠动画完成、重开、使用提示、通关、广告奖励完成等关键步骤保存稳定状态。拖动途中不逐帧写入存档；暂停时取消未提交动作并保存稳定位置。

地图内容版本变化时更新缓存地图并重置位置和该关完成/跳过标记，保留已消耗的免费提示和已确认奖励。当前地图版本为 3，防止旧版第一关地图继续出现在缓存中。

## 手动编辑

菜单：`Tools / PaperFold / 迷宫关卡编辑器`。

1. 从关卡列表选择当前关卡，填写名称、设计意图、卡点和解法。
2. 使用画道路、画墙工具按住拖动；另有设置起点、设置出口工具。
3. 设置折叠起始列和宽度，切换折叠预览，观察接缝。
4. 校验当前关或全部关卡。校验报告最短逻辑操作数与最少必要切换次数，不强制旧版前四关教学条件。
5. 修改地图后递增内容版本，再保存目录。Play 试玩使用独立内存存档。

保存时同步第一关到场景资源。代码重新导入后也会按内容签名同步一次；同步仅更新地图网格、折叠背景范围和起终点位置，保留用户相机、UI 和小球/目标预制体改动。可手动执行 `Tools / PaperFold / 同步手工关卡场景资源`。

## 验证

- `TEngine/Tests/Maze.Tests`：读取实际发布 JSON，校验唯一关卡、折叠必要性、合法提示、连续转向、穿过出口、存档迁移和广告回调；多关流程使用隔离的人工测试夹具，不写入发布目录。
- `TEngine/Tests/Maze.Geometry.Tests`：用最小数学适配层执行生产网格构造算法，检查分区边界和三角形有效性；不能代替 Unity 画面或真机性能测试。
- `TEngine/Tests/maze-reference-preview.png`：由相同道路三角形生成的展开/折叠几何对照图，不是 Unity 运行截图。
- HotFix 与编辑器通过 Unity 引用程序集的 C# 编译检查。当前运行中的 Unity 尚需刷新导入，完成资源同步后在 Game 窗口确认最终画面及手感。
